# Logo files

This folder is empty until the skill is configured.

During onboarding (`references/onboarding.md`, Step 5), the company's logo files are copied
here with stable names so that `applying-brand.md` can reference them reliably:

- `logo-on-light.png` — logo for use on light / white backgrounds
- `logo-on-dark.png` — logo for use on dark / brand-color backgrounds
- `mark.png` — logo mark / icon only, for favicons and tight spaces

Not every company supplies all three. The Logo table in `references/brand-profile.md`
records which files actually exist and which background each is for.
